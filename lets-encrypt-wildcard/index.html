Let's Encrypt Wildcard: бесплатный сертификат на поддомены, коротко и с данными

Конспект страницы: 7 разделов коротко, данные на 19 октября 2026 и ответы на 4 вопроса. Полный разбор с примерами: Let's Encrypt Wildcard: бесплатный сертификат на поддомены.

Коротко

Главная / Бесплатный / Wildcard бесплатно Let's Encrypt Wildcard выдаётся бесплатно на домен и все его поддомены, но только через DNS-подтверждение: в зону домена добавляют TXT-запись, а проверка по http для звёздочки не принимается. Бесплатный Wildcard возможен: Let's Encrypt выдаёт его только после проверки по DNS. Если у DNS-хостинга есть API, продление идёт автоматически, если нет, TXT-запись придётся менять вручную при каждом продлении.

Конспект по разделам

Что покрывает Wildcard-сертификат Let's Encrypt

Wildcard-сертификат выпускают на имя со звёздочкой, например *.example.com. Он подходит для любых поддоменов этого уровня: shop.example.com, blog.example.com, mail.example.com. Общее описание типа: Wildcard-сертификат.

Нужен ли вам Wildcard или хватит отдельных сертификатов

Бесплатные сертификаты Let's Encrypt можно выпускать на несколько имён сразу, а подтверждение по http автоматизируется проще, чем по DNS. Wildcard оправдан, когда поддоменов много или они появляются без вашего ведома, например у клиентов сервиса. Два ответа, и видно, нужен ли Wildcard и как его продлевать

Почему Wildcard от Let's Encrypt выдают только через DNS-01

Центр сертификации хочет убедиться, что вы управляете всем доменом, а не одним сайтом на нём. Для этого он просит добавить в DNS TXT-запись с именем _acme-challenge и выданным значением. Правило прописано в документации центра: Wildcard выдаётся только через DNS-01.

Как выпустить Wildcard через Certbot пошагово

Файлы появятся в /etc/letsencrypt/live/example.com/. Если Certbot ещё не установлен: установка Certbot. Ручной режим сам не продлевается Certbot не может добавить TXT-запись без вашей помощи, поэтому через 60 дней нужно повторить шаги.

  • Запустите Certbot с ручным режимом и проверкой по DNS.
  • Скопируйте имя и значение TXT-записи, которые выведет программа.
  • Добавьте запись в зону домена у DNS-хостинга и подождите, пока она станет видна.
  • Проверьте запись командой dig и только после этого нажмите Enter.

Как автоматизировать продление Wildcard-сертификата

У Certbot есть плагины для популярных DNS-хостингов, они сами создают и удаляют TXT-запись через API. Пример для Cloudflare: в файле с ключом API хранится токен, а команда выпуска выглядит так. Файл с токеном закройте от чтения другими пользователями: chmod 600.

Когда проще купить Wildcard, чем настраивать бесплатный

Если у DNS нет API, а поддомены нужны сейчас, платный Wildcard экономит время. В линейке Таймвеб на 19 октября 2026 есть два варианта. Когда платный сертификат оправдан, разобрано в статье бесплатный или платный SSL.

Вопросы и ответы

Можно ли получить Wildcard от Let's Encrypt бесплатно?

Да, центр не берёт плату за сертификаты, включая Wildcard. Условие одно: домен подтверждается через DNS-01, то есть TXT-записью.

Закрывает ли Wildcard-сертификат основной домен без поддомена?

Нет, *.example.com не включает example.com. Добавьте оба имени в заявку: -d example.com -d "*.example.com".

Почему Certbot не продлевает Wildcard автоматически?

В ручном режиме он не может сам менять DNS. Подключите плагин вашего DNS-хостинга или hook-скрипт, который создаёт TXT-запись через API.

Работает ли Wildcard на поддомены второго уровня?

Нет, *.example.com закрывает только один уровень. Для a.shop.example.com выпустите отдельный сертификат или Wildcard *.shop.example.com.
