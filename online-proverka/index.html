Коротко

Главная / Проверка / Онлайн-проверка Онлайн проверка SSL занимает пару минут: введите адрес сайта в сервис вроде SSL Labs, и он покажет срок, издателя, цепочку, поддерживаемые версии TLS и итоговую оценку от A+ до F. Устанавливать ничего не нужно, сервис подключается к сайту так же, как посетитель. Для полного отчёта берите SSL Labs, для быстрой справки о сроке и цепочке SSL Shopper.

Конспект по разделам

Как провести онлайн проверку SSL на SSL Labs

  • Откройте SSL Server Test на сайте ssllabs.com/ssltest.
  • Введите домен без https:// и поставьте отметку «Do not show the results on the boards», если не хотите, чтобы адрес попал в публичный список недавних проверок.
  • Дождитесь отчёта.
  • Прочитайте итог.

Какие сервисы проверяют сертификат сайта онлайн

У Таймвеб в разделе SSL тоже есть инструмент проверки сертификата сайта: он полезен, когда сертификат куплен там же. Все перечисленные сервисы проверяют публичный адрес. Для внутреннего сайта или сервера за фаерволом нужна проверка из терминала: проверка SSL через openssl.

На что смотреть в отчёте онлайн проверки SSL

Оценку читают после проверки пяти параметров. Каждый разобран отдельно, если что-то красное.

  • Срок действия.
  • Имена.
  • Цепочка.
  • Протоколы.

Что онлайн проверка SSL увидеть не может

Сервис подключается к сайту из интернета, поэтому видит только то, что видно любому посетителю. Он не проверит сайт в закрытой сети, домен, который ещё не направлен на сервер, и сертификат на нестандартном порту без указания порта. Кроме того, отчёт показывает состояние на момент запуска: вы поменяли сертификат пять минут назад, а сервер ещё не перечитал конфиг, и отчёт покажет старый.

Вопросы и ответы

Как бесплатно проверить SSL-сертификат сайта онлайн?

Все названные сервисы бесплатны: SSL Labs, SSL Shopper, Why No Padlock и crt.sh. Достаточно ввести домен, регистрация не нужна.

Можно ли загружать приватный ключ в онлайн проверку SSL?

Нет. Для проверки ключ не нужен, ему место только на вашем сервере. Если сервис просит ключ, закройте страницу.

Почему SSL Labs показывает оценку B при рабочем сертификате?

Сервер принимает устаревшие TLS 1.0 или 1.1, либо отдаёт неполную цепочку: обе причины ограничивают оценку на уровне B. Отключите старые версии TLS в конфиге.
