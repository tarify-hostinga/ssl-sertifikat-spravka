Для этого нужны ключи двух видов: пара открытый и закрытый для проверки сайта и один общий для быстрого шифрования. SSL работает в два приёма: сначала сертификат и закрытый ключ доказывают, что сервер настоящий, потом стороны вырабатывают общий ключ и шифруют им страницы.

Зачем SSL нужны три ключа: открытый, закрытый и сеансовый

Пара открытого и закрытого ключей даёт доверие, но вычисления с ней тяжёлые. Поэтому её используют только для знакомства, а основной поток данных шифруют симметричным алгоритмом, например AES: он работает быстро и одним ключом закрывает и открывает данные. Подробнее об алгоритмах: шифрование SSL.

Почему перехватчик не расшифрует переданные данные

Посторонний в той же сети видит зашифрованные байты. Сеансовый ключ по сети не передаётся: обе стороны вычисляют его сами из обмена, который сам по себе секрет не раскрывает. В TLS 1.3 для этого каждый раз берутся временные ключи, поэтому кража закрытого ключа сервера позже не позволит расшифровать записанный трафик.

Вопросы и ответы

Как работает SSL-сертификат на сайте?

Это удостоверение сайта: браузер сверяет его подпись с центром сертификации, которому доверяет, и только после проверки начинает шифровать обмен.

Шифрует ли сам сертификат данные?

Нет. Сертификат только подтверждает сайт и несёт открытый ключ, а данные шифрует протокол TLS по сеансовому ключу.

Как часто создаётся новый ключ шифрования?

Для каждого нового соединения вырабатываются свои ключи, поэтому запись одного сеанса не помогает расшифровать другой.

Работает ли SSL, если сайт открывается по ip-адресу?

Шифрование работает, но браузер сверяет имя в сертификате с адресом в строке. Обычный сертификат выпускают на домен, поэтому при заходе по IP он покажет несовпадение имени.

Справочник не связан с центрами сертификации, провайдерами и компаниями, упомянутыми на сайте. Названия и товарные знаки принадлежат правообладателям. Цены и условия сертификатов собраны вручную, у каждой цифры указана дата проверки, страницы обновляются по мере изменения тарифов. Методика: о проекте.
