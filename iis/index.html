SSL на IIS: импорт PFX и привязка https, коротко и с данными

Коротко

Главная / Установка / SSL на IIS SSL на IIS подключают в диспетчере служб IIS: сертификат попадает на сервер через компонент Server Certificates, затем у сайта добавляется привязка https на порт 443 с этим сертификатом. Сертификат переносят одним файлом PFX, где лежат сертификат, ключ и цепочка. В IIS хватит двух действий в диспетчере: импорт сертификата и привязка https.

Конспект по разделам

Какой файл сертификата принимает IIS

IIS хранит сертификаты в хранилище Windows и ждёт их в формате.pfx, он же PKCS#12. В этом файле лежат сразу три вещи: ваш сертификат, закрытый ключ и промежуточные сертификаты. Файл защищён паролем, который вы задаёте при создании.

Как импортировать PFX в IIS шаг за шагом

То же из консоли PowerShell: команда Import-PfxCertificate кладёт файл в хранилище компьютера. Есть и обратный путь: если запрос создан в самом IIS (пункт «Создать запрос сертификата»), ключ остаётся на сервере и файл PFX не нужен. Когда центр пришлёт ответ, нажмите «Завершить запрос сертификата».

  • Откройте диспетчер IIS.
  • Нажмите «Импортировать».
  • Выберите хранилище.
  • Проверьте список.

Как добавить привязку https к сайту в IIS

Когда на одном IP-адресе работают несколько сайтов, отметьте «Требовать указание имени сервера» (SNI). Тогда IIS по имени из запроса выбирает нужный сертификат. Опция появилась в IIS 8, то есть в Windows Server 2012.

  • Выберите сайт в дереве диспетчера и нажмите Bindings («Привязки») в правой панели.
  • Нажмите «Добавить».
  • Укажите тип https, порт 443 и, если сайтов несколько, имя узла, например example.com.
  • Выберите сертификат в списке «SSL-сертификат» и подтвердите.

Как проверить, что привязка https в IIS работает

В правой панели в блоке «Просмотр веб-сайта» появится ссылка с портом 443. Откройте её: в адресной строке должен быть замок. В документации Microsoft по IIS описан и более глубокий способ.

Вопросы и ответы

В каком формате сертификат ставят на IIS?

В формате PFX (PKCS#12): один файл с сертификатом, закрытым ключом и промежуточными сертификатами, защищённый паролем.

Как установить SSL-сертификат на несколько сайтов IIS с одним IP?

Импортируйте сертификаты в Server Certificates, затем в привязке https каждого сайта задайте имя узла и отметьте «Требовать указание имени сервера» (SNI).

Почему после импорта сертификата в IIS его нет в списке привязки?

Скорее всего, у импортированного сертификата нет закрытого ключа: в список попадают только сертификаты с ключом. Импортируйте полный PFX в хранилище компьютера.

Можно ли использовать бесплатный Let's Encrypt на IIS?

Да, сертификат подходит любому серверу. Для выпуска и продления на Windows нужен клиент ACME, принцип описан на странице про протокол ACME.
