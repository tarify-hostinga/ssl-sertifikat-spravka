Имя сертификата не совпадает с адресом сайта: коротко и с данными

Конспект страницы: 5 разделов коротко, данные на 19 октября 2026 и ответы на 3 вопроса. Полный разбор с примерами: Имя сертификата не совпадает с адресом сайта.

Коротко

Главная / Ошибки / Имя не совпадает Имя сертификата не совпадает с адресом, когда домен из адресной строки не входит в список имён сертификата: он выдан на example.com, а вы открыли www.example.com или поддомен. Браузер пишет NET::ERR_CERT_COMMON_NAME_INVALID, чинится ошибка перевыпуском сертификата на нужные имена. Браузер сверяет адрес со списком Subject Alternative Name.

Конспект по разделам

Как браузер сверяет имя сертификата с адресом сайта

Браузер берёт имя из адресной строки и ищет его среди имён сертификата в поле Subject Alternative Name (SAN). Старое поле Common Name (CN) Chrome с версии 58 не учитывает, поэтому «в сертификате же написан мой домен» не аргумент: он должен быть в SAN.

Почему имя сертификата не совпадает, хотя сертификат установлен

Заход по IP-адресу почти всегда даёт ту же ошибку: сертификат выдан на имя, а не на цифры.

  • В сертификате нет www.
  • Нет поддомена.
  • Домен не привязан к сертификату на сервере.
  • Запрос идёт на чужой сервер.

Как посмотреть список имён сертификата командой

Если в списке есть только moy-sayt.ru, а проблема на www, всё понятно. Если в списке имена другого сайта, сервер отдаёт сертификат по умолчанию. Тогда посмотрите, какие блоки заданы на сервере: sudo nginx -T | grep -E "server_name|ssl_certificate ", и добавьте отдельный блок с listen 443 ssl; и server_name для вашего домена.

Как перевыпустить сертификат сразу на домен, www и поддомены

Имена в готовом сертификате не поменять, нужен новый. С Certbot это одна команда: все имена перечисляют через -d. Для проверки владения каждое имя должно указывать на этот сервер, иначе выпуск по HTTP не пройдёт.

Вопросы и ответы

Сертификат выдан на домен без www, а сайт открывается с www: что делать?

Перевыпустите сертификат на оба имени. Редирект с www на основной адрес не помогает, пока браузер не принял сертификат на www.

Покрывает ли Wildcard сам домен без поддомена?

Нет, запись *.site.ru закрывает только поддомены первого уровня. Обычно Wildcard выпускают на два имени: site.ru и *.site.ru.

Почему при заходе на сайт браузер показывает сертификат другого сайта?

Сервер не нашёл блок для вашего домена и отдал сертификат по умолчанию, либо домен направлен на чужой хостинг. Добавьте виртуальный хост и проверьте A-запись.
